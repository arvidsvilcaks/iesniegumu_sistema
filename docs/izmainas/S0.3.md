# S0.3 · Automātiskais pieejamības tests

**Kas mainīts**
- Uzstādīts Chromium priekš Playwright: `python -m playwright install --with-deps chromium`.
- `tests/a11y_check.py`: jauns vides mainīgais `LOMA`. Tests vispirms sākumlapā izvēlas lomu un tikai tad apstaigā lapas, tāpēc axe pārbauda arī darbinieka un vadītāja lapas.

**Lietošana** (lietotnei jābūt startētai)
```
python tests/a11y_check.py                    # publiskās lapas
LOMA=darbinieks python tests/a11y_check.py    # + saraksts un visas detaļu lapas
LOMA=vaditajs python tests/a11y_check.py      # + pārskats
```

**Rezultāts (2026-10-14)**: visās trīs palaišanās critical 0, serious 0, moderate 0, minor 0.

Papildus ar Playwright pārbaudīti stāvokļi, kurus rāpulis neaizsniedz. Arī tajos ir 0 pārkāpumu:
- formas kļūdas: fokuss uz kopsavilkumu, saite kopsavilkumā fokusē lauku;
- apstiprinājuma lapa;
- paziņojums pēc statusa maiņas (fokuss uz `#pazinojums`);
- kļūda detaļu lapā;
- lapas «Nav piekļuves» un «Lapa nav atrasta».

Pārbaudīts arī, ka pirmais Tab fokusē «Pāriet uz saturu».

**Reflow 320 px**: atrasta horizontālā ritjosla detaļu lapā (datu saraksts `<dl>` 340 px). Izlabots `static/style.css`: šaurā ekrānā saraksts ir vienā kolonnā. Tagad visas lapas ir ≤ 320 px.
